# 新世界 · The New World

**用代码堆砌的现实。** 每一块砖都来自真实世界：国界来自 Natural Earth，
人口与经济来自世界银行，碳排放来自 Our World in Data——把它们砌进一个
可在浏览器里旋转、拨动时间、点亮城市灯火的世界。

```
 ● 真实数据（可溯源、离线可用）
 ◎ 简洁规律（历史是数据，未来是规律）
 ▣ 浏览器交互（旋转 / 拾取 / 时间轴 / 模式切换）
```

## 打开世界

```bash
git clone https://github.com/alishangtian/the-new-world.git
cd the-new-world
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

零依赖、零构建、离线可用（数据随仓库提交）。任何静态文件服务器都可以。

## 你能做什么

| 操作 | 效果 |
|------|------|
| 拖拽 / 滚轮 | 旋转地球、缩放 |
| 点击国家 | 国别档案：人口、GDP、人均 CO₂、1960→2050 人口轨迹（实线历史 + 虚线规律外推） |
| 拨时间轴 1960↔2050 | 城市灯火随人口律呼吸；未来由逻辑斯蒂增长模型接管 |
| 速度档位 | 实时 / 1天/秒 / 1月/秒 / 1年/秒 / 10年/秒——看着晨昏线扫过大地 |
| 模式：人口 / 经济 / 碳 | 各国数据 choropleth（对数色带） |
| 左侧面板 | 六块知识砖的规律与来源，开关即拆装世界 |

## 六块知识砖

| 砖 | 编码的现实 | 规律 |
|----|------------|------|
| 星海 · 舞台 | 程序化星空（固定种子） | 背景律：时间由此可感 |
| 大地 · 疆界 | 177 国真实边界 | L2 透镜律：正交投影 + 可见半球裁剪 |
| 昼夜 · 晨昏线 | 实时太阳直射点 | L1 自转律 + L3 昼夜律（几何正确的夜半球） |
| 生命 · 城市灯火 | 600 座真实城市 | L4 人口律：历史插值 + 逻辑斯蒂外推 |
| 联结 · 引力航线 | 城市间大圆航线 | L5 引力律：I ∝ Pᵢ·Pⱼ/d² |
| 碳 · 余烬 | 高排放国呼吸光环 | L6 碳律：TCRE 线性气候响应 |

全部规律与简化假设见 **[LAWS.md](LAWS.md)**；每个数字的来源与许可见 **[docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)**。

## 技术决策（为什么是领先的）

- **零运行时依赖**：原生 ESM + Canvas 2D。不背框架，五年后依然能跑。
- **离线优先**：数据随仓库提交（~1MB），采集脚本可重复运行、幂等。
- **可溯源强制化**：砖块契约要求 `sources` 字段，CI 校验 URL 合法性。
- **规律优先于特效**：晨昏线是算出来的（不是贴图），人口未来是模型（不是动画）。
- **AI 原生仓库**：内置 `world-builder` 施工技能（`.zcode/skills/world-builder/`），
  人类与 AI 按同一本手册施工；`verify.mjs` 体检（数据/契约/无头渲染/拾取回归）守住质量红线。
